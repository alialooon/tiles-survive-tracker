# Tiles Survive Tracker — поиск поселения (v6, revision 9)

Цель по умолчанию: **KingBonbee**, штат **752**.

## Как запустить
1. Закройте предыдущий Tracker и запустите прежний **start_windows.bat**. Автообновление установит новую версию. В первый раз Python загрузит библиотеки RapidOCR, ONNX Runtime и MSS, поэтому нужен интернет.
2. Откройте мировую карту штата 752 в Tiles Survive. Уменьшите масштаб до последнего положения, при котором никнеймы **ещё видны**.
3. В Tracker нажмите **«Начать поиск»**. Tracker свернётся. Переключитесь на игру и медленно проведите карту последовательными перекрывающимися полосами. Программа не двигает карту за вас.
4. Для остановки верните Tracker из панели задач и нажмите «Остановить». **Дождитесь, пока «Очередь» не станет 0**: накопленные кадры продолжают обрабатываться.
5. Если найден возможный ник — прозвучит сигнал. Через «Открыть находки» откройте сохранённый PNG с рамкой и вручную подтвердите, что это искомое поселение.

## Скорость, качество и ограничения
- Частота **захвата** нацелена на ~8 FPS. Каждые ~0,3 секунды отбирается наиболее резкий новый кадр. **Скорость распознавания OCR может быть значительно ниже** и зависит от CPU.
- Индикаторы: Кадров, OCR, Надписей, Находок, Очередь и Пропущено.
- Если счётчик **Надписей = 0** после 15+ обработанных кадров, слегка приблизьте карту. Если очередь заполняется, замедлите прокрутку.
- При переполнении очереди кадры пропускаются и учитываются; 100% охват всей карты не гарантируется.
- Сохраняются только кадры с **вероятными совпадениями** в локальной папке результатов. Возможны ложные срабатывания.
- Из снимка нельзя автоматически получить **точные координаты поселения**: координаты вверху интерфейса — центр отображаемой карты.
- Игрок может перемещаться между уже проверенными областями.

## Система и доступ
- Действия в игре полностью ручные. Доступ к памяти и сетевому обмену игры отсутствует. Автоматическая программа чтения экрана **не гарантирует незаметность или соответствие правилам FunPlus**.
- Результаты: %LOCALAPPDATA%\TilesSurviveTracker\player_search
- Диагностика OCR: %LOCALAPPDATA%\TilesSurviveTracker\player_search.log
- Проблемы запуска: tracker-startup.log в папке установленного Tracker.

## Проверки
11 локальных тестов распознавания, нормализации имён и ограниченного захвата, плюс графический smoke-тест, пройдены. Полную работу с Windows/игрой пока необходимо проверить на пользовательском ПК. В тестовом контейнере RapidOCR и ONNX Runtime не устанавливаются из-за отсутствия доступа к сети.
