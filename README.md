# Tiles Survive Tracker — Revision 11

Неофициальный Windows-наблюдатель карты игры. Захватывает только видимую область окна Tiles Survive, **не управляет игрой**, не читает её память и не перехватывает игровой трафик.

## Поиск по никнейму

Текущая цель: **KingBonbee**, штат **752**, союз **[MTT]**.

Раньше совпадениями считались частично похожие имена, включая `bonbee` на интерфейсе маршей. Теперь сигнал подаётся **только при полном совпадении распознанного никнейма** с заданным. Поддерживается префикс союза вида `[MTT]KingBonbee`. Это снижает ложные сигналы, но может пропустить настоящее имя, если OCR неправильно прочитало хотя бы один символ.

## Новый интерфейс

- **Левая область:** последнее изображение видимой части карты (обновляется во время поиска, отображается когда окно Tracker возвращено с панели задач).
- **Правая область:** посещённые центры в игровых координатах X/Y. Зелёные точки — **фактически прочитанные** координаты, жёлтая — последняя координата. Если координаты из игровой строки не прочитаны, карта не придумывает точки.
- **Начать/Остановить поиск**, **Открыть находки** — основные кнопки. Карта перемещается **только вручную**, без управления игрой.

### Что показывает карта посещений

Tracker использует строку `#752 X:483 Y:545` в верхней части игрового окна. OCR отдельно распознаёт координаты примерно каждый третий обработанный кадр. Из них строится маршрут в масштабе **наблюдавшихся координат**; он не является географической картой штата и не показывает достоверный процент всей обследованной территории. Реальное покрытие экранов потребует отдельной калибровки масштаба и видимого охвата.

Точки сохраняются между сеансами в папке:
`%LOCALAPPDATA%\TilesSurviveTracker\player_search\coverage_752.jsonl`

### Подтверждение находки

Результаты `candidate_*.png` сохраняются с красной рамкой вокруг совпавшего имени. В `candidates.jsonl` есть поле `camera_center_xy`, если координаты центра карты удалось распознать **на этом же кадре**. Это **не координаты самого поселения**; для получения точного X/Y нужно после находки проверить расположение поселения в игре.

## Обновления

Закройте Tracker, затем снова запустите **уже установленный `start_windows.bat`**. Запускатор скачает `launcher.py` по манифесту `manifest.json`, проверит SHA-256 и запустит установленную программу. Новые ZIP архивы скачивать не нужно.

Если возникла ошибка, откройте `tracker-startup.log` рядом с BAT, либо `%LOCALAPPDATA%\TilesSurviveTracker\player_search.log`.

Локальные тесты подтвердили обработку строгих имён, OCR-координат и отображение маршрута в тестовой среде Linux с виртуальным дисплеем. Реальное качество распознавания координат на твоём Windows-клиенте пока не проверено. Приложение не гарантирует невидимость для разработчиков или соответствие правилам FunPlus.
