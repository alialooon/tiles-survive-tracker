# Tiles Survive Tracker

Неофициальная Windows-программа для локального анализа изображения карты Tiles Survive. Она не управляет мышью или игрой.

## Исправление запуска версии 0.5

В первоначальном ZIP-архиве от 23.10.2026 файл `start_windows.bat` был записан с Unix-окончаниями строк LF, которые вызывали ошибку в Windows cmd. Исправленный `start_windows.bat` здесь сохранён с CRLF.

1. Распакуйте полный архив Tracker 0.5 в обычную папку (например, `Desktop\TS checker`). Должны присутствовать `launcher.py`, `updater.py`, `app.py` и `VERSION`.
2. В этой папке в адресной строке Проводника наберите `cmd`.
3. Для однократной замены сломанного запускатора выполните:

```cmd
powershell -NoProfile -Command "Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/alialooon/tiles-survive-tracker/main/start_windows.bat' -OutFile 'start_windows.bat'"
start_windows.bat
```

Если пакетный файл снова выдаёт ошибку, откройте `tracker-startup.log` в этой же папке. Скрипт показывает ошибки и не закрывает консоль при неуспешном запуске.

> Если после запуска появляется сообщение `launcher.py not found`, вы запускаете файл из папки без остальных исходников Tracker. Не помещайте BAT отдельно.

## Обновления

В версии 0.5 есть опциональная проверка обновлений при запуске. **Важно: выпускной источник `updates.json` и архивы релизов в этом репозитории ещё не опубликованы.** Не добавляйте адрес манифеста до появления проверенного релиза.

Функция автообновлений проверяет HTTPS-манифест с версией и SHA-256 архивом и устанавливает новые версии в отдельные папки. Из чата нельзя удалённо менять файлы на пользовательском ПК; для установки нужно один раз исправить запускатор и затем настроить источник обновлений в программе.

Программа неофициальная, не утверждается что она разрешена условиями игры.
