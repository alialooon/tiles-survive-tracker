# Tiles Survive Tracker — обновления без ручной загрузки ZIP

Экспериментальный **локальный Windows-наблюдатель** для карты Tiles Survive. Не управляет игровыми действиями.

## Один раз: исправить старый запускатор

Если пакет `TilesSurviveTracker-v0.5-Windows-AutoUpdate.zip` уже распакован (например, `C:\Users\alialooon\Desktop\TS checker`), откройте именно эту папку в Проводнике, введите `cmd` в адресной строке и выполните **одну команду**:

```cmd
powershell -NoProfile -Command "Invoke-WebRequest -UseBasicParsing 'https://raw.githubusercontent.com/alialooon/tiles-survive-tracker/main/start_windows.bat' -OutFile 'start_windows.bat'" && call start_windows.bat
```

После этого запускайте **тот же `start_windows.bat`** обычным двойным щелчком. Он обращается к `tracker-bootstrap.ps1` в GitHub, проверяет `manifest.json`, загружает только изменённые файлы с проверкой SHA-256, создаёт виртуальную среду Python (если её нет) и запускает `launcher.py`. Повторно скачивать ZIP в дальнейшем не требуется при штатных обновлениях.

**Для первого запуска полная распакованная версия 0.5 всё равно необходима**: в ней должны лежать `app.py`, `windows_capture.py`, `engine.py`, `survey.py`, `tracker.py`, `requirements.txt` и т. д. Файл `start_windows.bat` сам по себе не содержит приложение.

## Статус публикации

- `start_windows.bat`: исправлен Windows CRLF, запускает постоянный загрузчик.
- `tracker-bootstrap.ps1`: опубликован, проверяет и применяет обновления.
- `manifest.json`: опубликован, **revision 3** обновляет только `launcher.py` (совместим со старым загрузчиком).
- `launcher.py`: опубликован; содержит встроенное исправление захвата DirectX/Unity (дополнительные файлы не требуются).
- Встроенный в `launcher.py` захват при пустом `PrintWindow` пробует активировать Tiles Survive и снимает **только клиентскую область** выбранного окна. Не эмулирует мышь и не перемещает карту.
- Полный исходный код базовой версии 0.5 пока хранится в предыдущем архиве, а не во всех файлах репозитория. Для последующих исправлений дополнительные изменённые файлы будут добавляться в репозиторий и в `manifest.json`.

**Кнопку «Настроить автообновления» внутри старого окна Tracker заполнять не нужно**: прежняя система `updates.json` больше не является основным механизмом. Новая проверка выполняется при запуске BAT.

## Если не открывается

Откройте файл `tracker-startup.log` рядом с `start_windows.bat`. Запускатор теперь показывает ошибки и не закрывает консоль при неудаче. Убедитесь, что установлен Python 3.10 или новее и доступны установочные пакеты Python.

## Безопасность и ограничения

Исходники и загружаемый код доступны по HTTPS с GitHub. Манифест указывает ожидаемые контрольные суммы SHA-256, что предотвращает случайное повреждение загружаемых файлов, но **не защищает от компрометации аккаунта GitHub**. Доверяйте только владельцу репозитория. Из чата невозможно напрямую изменять файлы на вашем компьютере; установка обновлений происходит при локальном запуске. Захват реального окна игры пока не подтверждён тестом на пользовательской Windows.

## Исправление ошибки «Игровой движок не передал отдельный кадр окна» (revision 2)

Закройте Tracker и повторно запустите **уже установленный** `start_windows.bat`. Проверка обновлений с GitHub должна установить `launcher.py` и `capture_hotfix.py`. Затем в игре откройте карту, а в Tracker нажмите «Найти окно игры» и «Снять изображение окна игры».

Если Unity не даёт кадр через `PrintWindow`, модуль пробует активировать Tiles Survive и получить ограниченный снимок клиентской области через GDI/ImageGrab. **Проверено тестами с имитацией Win32; на реальном ПК и конкретном клиенте Tiles Survive ещё не проверено.** Если Windows запрещает смену фокуса, переключитесь на игру вручную и повторите захват. Если программа по-прежнему выдаёт ошибку, проверьте `tracker-startup.log` и пришлите текст ошибки — игровой аккаунт, токены и пароли не нужны.

## Исправление ошибки «Invalid update file or checksum: capture_hotfix.py» (revision 3)

Ошибка возникала потому, что предыдущий релиз требовал новый файл `capture_hotfix.py`, а ранее установленный загрузчик разрешал обновление только известных ему имён файлов. В **revision 3** исправление находится в старом разрешённом файле `launcher.py`, а манифест больше не содержит `capture_hotfix.py`.

Для пользователя: **закройте окно с ошибкой и запустите тот же `start_windows.bat`**. Никакой ZIP или новый BAT загружать не нужно. GitHub может временно отдавать закэшированный старый манифест; в новой версии `tracker-bootstrap.ps1` используются уникальные параметры URL, чтобы получать свежий манифест и файлы. Если сразу после публикации снова появляется та же ошибка, не переустанавливайте Tracker: повторите запуск спустя несколько минут.

**Проверка:** опубликованный `launcher.py` имеет SHA-256 `cacd97e23c9536b42d9019555d20ceb15060c879ac29f792701f0e27aac0187d`. На Linux с имитацией графических функций Windows успешно прошли 26 тестов основного приложения и 5 тестов поведения fallback-захвата; работа настоящего игрового окна Windows требует проверки на пользовательском устройстве.
