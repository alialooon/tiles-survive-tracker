# Tiles Survive Tracker

Локальный Windows-наблюдатель для карты Tiles Survive. Программа анализирует видимое изображение игры и **не отправляет команды в игру**.

## Новый интерфейс — Revision 5

После запуска через установленный `start_windows.bat` обновление устанавливается автоматически и открывается компактное окно с **тремя кнопками**:

- **▶ Начать поиск / ■ Остановить поиск** — одна кнопка для всего сеанса. Приложение обнаруживает окно Tiles Survive автоматически, сворачивается, делает снимки видимой области с интервалом ~2,5 секунды, пропускает знакомые кадры и сохраняет результаты. Для остановки верните окно Tracker с панели задач.
- **Настроить маркер** — требуется один раз или при смене типа искомого значка. Приложение делает снимок игры; выделите мышью один характерный ресурсный маркер. Образец сохраняется в настройках, поиск начинается автоматически.
- **Открыть находки** — показывает локальную папку результатов.

Не нужно нажимать «Снять кадр», «Найти точку», «Сохранить» после каждого сдвига карты. Перемещение по карте остаётся **ручным**, чтобы не автоматизировать игровые действия. Это снижает число взаимодействий с игрой, но не гарантирует соблюдение правил и отсутствие обнаружения.

### Точность результатов

Это **поиск визуально похожих маркеров**, а не достоверное определение владельцев или координат X/Y на карте. При сомнении проверяйте находку вручную. Различимость точек внутри сеанса приблизительная: при невозможности совместить соседние кадры возможны дубликаты. История, отмеченные PNG и CSV хранятся только локально.

## Установка и обновления

В папке первоначальной полной версии Tracker (обязательно должны быть `app.py`, `engine.py`, `tracker.py`, `survey.py`, `windows_capture.py` и зависимости) запустите `start_windows.bat`. При запуске он проверяет `manifest.json` в этом репозитории и сверяет SHA-256 обновлённого `launcher.py`.

Обычная работа **не требует загрузки новых ZIP или самостоятельной настройки кнопок обновления**. Настроенная базовая папка остаётся прежней. При ошибке запускатора смотрите `tracker-startup.log`.

Первоначальная версия исходников должна уже быть распакована: GitHub содержит механизм обновления и патчи, а не полный самостоятельный установщик. Из чата нельзя напрямую управлять пользовательской Windows-машиной.

### Диагностика

Если окно игры найдено, но снимок пустой, откройте карту в обычном оконном режиме; Tracker пытается запросить клиентский кадр, а если это невозможно — получить **только видимую клиентскую область** активного игрового окна. При перекрытиях или потере фокуса кадр может не получиться. Снимок всего рабочего стола не сохраняется.

Проверки сделаны на искусственной карте в Linux с имитацией окна и базовых API; распознавание и качество работы с реальным клиентом требуют настройки на пользовательской Windows. Не отправляйте никнеймы и игровые скриншоты третьим лицам без проверки.

## Поиск поселения KingBonbee в штате #752 — Revision 6

В новой версии главная задача Tracker — **поиск ника на просматриваемой мировой карте**, а не поиск ресурсных маркеров.

1. Запустите Tiles Survive и откройте мировую карту штата **752**, масштаб с видимыми под поселениями именами.
2. Закройте прежний Tracker и запустите тот же `start_windows.bat`. При первом запуске этой ревизии автоматически установятся локальные OCR-библиотеки `rapidocr` и `onnxruntime` (потребуется интернет).
3. В Tracker уже стоят `KingBonbee` и `752`. Нажмите **«▶ Начать поиск»**. Приложение свернётся.
4. Медленно просматривайте карту **мышью**. Tracker будет делать снимки, пропускать ранее виденные участки и локально считывать текст. Игра не получает автоматических нажатий, свайпов или команд.
5. При возможном совпадении программа остановится, покажет снимок с жёлтым прямоугольником и сохранит PNG и JSON в локальной папке `player_matches`, доступной через «Открыть находки».

Важно:
- OCR обнаруживает **кандидата по написанному нику**, а не доказывает владельца поселения. Окончательно проверяйте его, нажав на поселение в игре.
- **X/Y пока не определяются автоматически**: цифры в верхней части карты — ориентир отображаемого участка, не координаты каждого здания.
- Если игрок сменил имя, не находится в просматриваемой части карты или подпись закрыта интерфейсом, программа может ничего не обнаружить.
- OCR тестировался логикой совпадения текста и совместимостью API по документации, но ещё не проверен в установленном Windows-клиенте пользователя. При ошибке пришлите `tracker-startup.log`.
